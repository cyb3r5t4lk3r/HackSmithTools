Potřebuji naprogramovat LinkedIn scraper pro extrakci osob přidružených ke konkrétní společnosti. 
Místo přístupu přes API LinkedIn (které je dostupné jen vybraným uživatelům) potřebuji extrahovat data přímo z webu. 

Protože bych použil PowerShell tak je určitě možné využít nějaké třídy přímo z Windows místo použití Selenium scriptů. Minimalizuj počet řádků kódu, ale přidávej všude debug log v různých barvách, který volej jako funkci. Snaž se dělat vše v malých funkcích, které se budou dobře ladit.
Pro kódování scriptu použijeme powershell, který je ve Windows x64 (Windows 11) a pro automatizaci použiejme Selenium modul pro powershell, který se nainstaluje, pokud neexistuje v systému. Další moduly se taktéž nainstalují, pokud jsou potřeba a v systému neexistují. Ideálně bychom měli použít pro přístup Microsoft Edge, který bude vždy ve Windows a neměli bychom spoléhat na dostupnost Chrome a nebo Firefox ve Windows.
Na stránce je uvedeno jak lze používat Selenium v powershell https://www.zenrows.com/blog/selenium-powershell#extract-data
TAktéž je potřeba psát kód powershell tak, že proměnné použité v "" budou zapisovány vždy takto $($promena) místo klasického použití $promena

Konkrétní požadavky na scraper:
1. Vstup bude ID společnosti. Například pro "pro.med.cs" je ID "660532".
2. Scraper musí využít URL formátu: https://www.linkedin.com/search/results/people/?currentCompany=[%22ID%22]&origin=COMPANY_PAGE_CANNED_SEARCH&sid=XXX
3. Musí implementovat procházení stránkování (URL s parametrem page=X).
4. Pro každou nalezenou osobu chci extrahovat:
   - Jméno
   - Pozice ve firmě
   - Lokalita
   - URL profilu
   - Profilový obrázek (stáhnout do lokálního adresáře)
5. Výstup ukládat ve formátech:
   - JSON
   - CSV
6. Scraper musí podporovat:
   - Přihlášení s podporou MFA (dvoufaktorové ověřování) a bude řešeno interaktivním přihlášením
   - Možnost ručního přihlášení v prohlížeči a následné automatické zpracování


Příklad použití by mohl vypadat takto LinkedInPeopleScrapper.ps1 --company "660532" --manual-login --visible
